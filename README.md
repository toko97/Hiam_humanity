# המילים שלי – סטודיו כרטיסים

תוכנה לסדנת המחשבים הפרטנית של היאם: בכל מפגש היאם בוחרת נושא, מנסחת עליו משפט או שניים משלה,
ומכוונת את עיצוב הכרטיס (תמונה, צבעים, גופן). בסוף השנה הכרטיסים מאוגדים לחוברת PDF.

**נושא-העל של הפרויקט:** אנושיות במאה ה-21. הנושא מופיע בראש מסך הנושאים, ואפשר לשנות אותו בכפתור "שינוי" לכל פרויקט חדש.
כל כרטיס עוסק בנושא משנה (חמלה, בדידות, טכנולוגיה וקשר אנושי ועוד), ו-Claude מחבר אותו בעדינות לנושא-העל, בלי לכפות.

התוכנה מבוססת על מטרות הדוח לקראת יום ההיערכות:
- **מטרה תפקודית:** תכנון והכוונה של תוצר גרפי שלם, מבחירת הנושא ועד אישור העיצוב. בכל שלב היאם בוחרת מבין אפשרויות, והמדריך מתפעל.
- **מטרה רגשית:** ביטוי עצמי ומתן תוקף לקולה. הניסוח נבנה מהמילים שלה, ו-Claude לא מוסיף תוכן משלו.
- **יעד:** לפחות 20 כרטיסים. מד ההתקדמות נמצא במסך "הכרטיסים".

## איך זה עובד: 5 שלבים לכל כרטיס

1. **נושא:** בחירה מרשימת נושאים, שאפשר להוסיף לה ולמחוק ממנה. ✓ מסמן נושאים שכבר נכתב עליהם.
2. **שיחה:** Claude שואל שאלה מכווינה אחת בכל פעם, לפי מה שהיאם כבר ענתה.
   לכל שאלה יש גם ניסוח פשוט יותר ותשובות לדוגמה שאפשר לבחור.
   אפשר להקליד או להכתיב בקול (🎤, עובד בכרום). כש-Claude מזהה מצוקה בתשובות, מופיעה למדריך הצעה לעצור.
3. **משפט:** שלוש הצעות ניסוח שנבנות מהמילים של היאם. היאם בוחרת אחת, ואפשר לשנות כל מילה.
4. **עיצוב:**
   - **סגנון:** גלריה של 10 סגנונות, מתוכם 5 מופשטים. "מופשט רך" הוא ברירת המחדל.
     הכפתור "יצירת תמונת דוגמה לכל סגנון" יוצר פעם אחת תמונה אמיתית לכל סגנון, כדי שהיאם תבחר לפי מה שהיא רואה.
   - **תמונה:** Claude מציע 3 רעיונות. אפשר גם לתאר במילים שלכם או להעלות תמונה מהמחשב (למשל מקנבה).
   - **צבעים, גופן, גודל טקסט ופריסה:** תצוגה מקדימה מתעדכנת בכל שינוי.
5. **אישור:** "✓ היאם מאשרת", והכרטיס נכנס לחוברת.

**החוברת:** שער (כותרת, צבעים, גופן ותמונה), סדר הכרטיסים שהיאם קובעת בעזרת חצים, וכפתור **הפקת PDF**.
החוברת יוצאת בגודל A5, כרטיס בכל עמוד. בחלון ההדפסה בוחרים "שמירה כ-PDF".

## התקנה והפעלה

צריך [Node.js](https://nodejs.org) בגרסה 22 ומעלה.

```bash
npm install
```

```bash
cp .env.example .env
```

פותחים את `.env` ומדביקים את המפתחות (ראו בהמשך). אחר כך:

```bash
npm start
```

ונכנסים בדפדפן לכתובת **http://127.0.0.1:3000**.

## מפתחות API

| מפתח | בשביל מה | חובה? |
|---|---|---|
| `ANTHROPIC_API_KEY` | שאלות מכווינות, הצעות ניסוח, רעיונות לתמונה ולצבעים | מומלץ מאוד. בלעדיו יש שאלות קבועות ואין הצעות |
| `OPENAI_API_KEY` **או** `GEMINI_API_KEY` | יצירת התמונות. Claude לא מייצר תמונות | מומלץ. בלעדיו אפשר להעלות תמונות מהמחשב |

- **ספק התמונות** נבחר ב-`IMAGE_PROVIDER=openai` (ברירת המחדל) או `IMAGE_PROVIDER=gemini`. מספיק מפתח אחד.
- המפתחות נשמרים רק בקובץ `.env` על המחשב שלכם. הקובץ לא נכנס לגיט ולא נשלח לדפדפן.
- המודל של Claude: `claude-opus-5-5`. אפשר לשנות דרך `CLAUDE_MODEL` בקובץ `.env`.

## פרטיות

- כל התוכן (תשובות, כרטיסים ותמונות) נשמר **רק על המחשב הזה**, בתיקייה `data/`. התיקייה לא נכנסת לגיט.
- השרת נגיש רק מהמחשב הזה (`127.0.0.1`).
- המידע שיוצא החוצה: הנושא והתשובות נשלחים ל-Claude כדי לנסח שאלות והצעות, ותיאור התמונה נשלח לספק התמונות.
  השם של היאם לא נשלח, חוץ מהחתימה "היאם" כשנכתבת בתשובות עצמן.
- **גיבוי:** כדאי להעתיק מדי פעם את התיקייה `data/` לדיסק און קי.

## מבנה הקוד

```
server/index.js   שרת Express: נתונים, נקודות קצה ל-AI, שמירת תמונות
server/ai.js      הנחיות ל-Claude (בעברית, אפשר לערוך), סגנונות וגופנים
server/images.js  יצירת תמונות דרך OpenAI או Gemini
server/store.js   שמירה בקובץ data/db.json
public/           הממשק: index.html, app.js, styles.css
```

כדי לשנות את אופי השאלות, עורכים את הטקסטים בעברית בקובץ `server/ai.js`.
